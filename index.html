룬드빅

조립도를 원본 PDF에서 다시 뽑아 스텝 단위로 잘랐다. 자르는 선은 조립도가 원래 그어 둔 칸 구분선이라 글자나 그림이 잘리지 않는다. 도면을 누르면 전체화면.

  1. 1

    수납 파데 ① 마이다 + 측판 + 중간판

    마이다 1개를 바닥에 놓고, 측판 2개와 중간판 1개를 미니픽스로 조립합니다. 지판 2개를 홈에 끼웁니다.

    조립도_수납파데마에다 측판2EA / 중간칸막이1EA 지판2EA 보강목2EA 마에다 마감스티커 1 / 2
  2. 1

    수납 파데 ① 마이다 + 측판 + 중간판 이어서

    조립도_수납파데마에다 측판2EA / 중간칸막이1EA 지판2EA 보강목2EA 마에다 마감스티커 2 / 2
    미니픽스 set측판 2ea중간판 1ea지판 2ea
    ⚠️ 방향 주의

    측판은 미니픽스 하우징이 바깥쪽을 향하도록 두세요. 반대로 두면 다음 단계에서 헤드와 결합 불가.

  3. 2

    수납 파데 ② 보강목 + 남은 마이다

    보강목 2개를 미니픽스 + 목다보로 조립합니다. 남은 마이다 1개를 추가하면 수납 파데가 완성됩니다. 세워주세요.

    조립도_수납파데마에다 측판2EA / 중간칸막이1EA 지판2EA 보강목2EA 마에다 마감스티커 1 / 2
  4. 2

    수납 파데 ② 보강목 + 남은 마이다 이어서

    조립도_수납파데마에다 측판2EA / 중간칸막이1EA 지판2EA 보강목2EA 마에다 마감스티커 2 / 2
    보강목 2ea목다보 4ea마감스티커 4ea
  5. 3

    서랍 파데 ① 지판 + 측판 4개

    지판 전면·후면을 바닥에 놓고, 측판 4개를 미니픽스로 결합합니다.

    조립도_서랍파데지판전면/후면 측판4EA 뒷판(우라) 1EA 언더레일6EA 상판1EA 1 / 2
  6. 3

    서랍 파데 ① 지판 + 측판 4개 이어서

    조립도_서랍파데지판전면/후면 측판4EA 뒷판(우라) 1EA 언더레일6EA 상판1EA 2 / 2
    ⚠️ 헤드 결합 보링 방향

    측판의 헤드 결합용 보링이 지판(전면)을 향하도록 두세요. 전면/후면 구분 필수.

  7. 4

    서랍 파데 ② 언더레일 + 천판

    언더레일을 측판 유도보링에 맞추어 전용 피스 3개씩 설치합니다. 천판을 미니픽스로 결합.

    조립도_서랍파데지판전면/후면 측판4EA 뒷판(우라) 1EA 언더레일6EA 상판1EA 1 / 2
  8. 4

    서랍 파데 ② 언더레일 + 천판 이어서

    조립도_서랍파데지판전면/후면 측판4EA 뒷판(우라) 1EA 언더레일6EA 상판1EA 2 / 2
    언더레일 3 set전용피스 18ea미니픽스 15 set
    📐 슬하 맞추기

    정면 기준으로 좌측·우측 모두 언더레일과 측판이 슬하가 일치해야 서랍이 부드럽게 들어갑니다.

  9. 5

    SS / Q·K 헤드(풋보드) 결합

    수납 파데를 먼저 설치한 후, 위치를 조정해서 서랍 파데를 설치합니다. 헤드/풋보드를 연결볼트·너트로 체결.

    조립도_SS 헤드(풋보드) + 파운데이션헤드/후드각1EA 수납파데 (위치조정) 서랍파데 서랍및덮개 (패널미조립경우) 마감스티커 1 / 2
  10. 5

    SS / Q·K 헤드(풋보드) 결합 이어서

    조립도_SS 헤드(풋보드) + 파운데이션헤드/후드각1EA 수납파데 (위치조정) 서랍파데 서랍및덮개 (패널미조립경우) 마감스티커 2 / 2
    ⛔ 보링 위치 주의

    수납 파데는 안쪽 보링, 서랍 파데는 바깥쪽 보링에 연결합니다. 반대로 하면 사이즈가 맞지 않습니다.

  11. 6

    속서랍 설치 (3개)

    속서랍 3개와 수납 파데 덮개 2개를 조립합니다.

    조립도_SS 헤드(풋보드) + 파운데이션헤드/후드각1EA 수납파데 (위치조정) 서랍파데 서랍및덮개 (패널미조립경우) 마감스티커 1 / 2
  12. 6

    속서랍 설치 (3개) 이어서

    조립도_SS 헤드(풋보드) + 파운데이션헤드/후드각1EA 수납파데 (위치조정) 서랍파데 서랍및덮개 (패널미조립경우) 마감스티커 2 / 2
  13. 7

    Q확장 파데 (Q / K 사이즈만)

    가로 판넬과 세로 판넬을 결합하고 덮개를 덮습니다.

    조립도_ Q/K 헤드(풋보드) + 파운데이션헤드/후드각1EA 수납파데 (위치조정) 서랍파데 Q확장파데 서랍및덮개 (패널없는경우) 마감스티커 1 / 2
  14. 7

    Q확장 파데 (Q / K 사이즈만) 이어서

    조립도_ Q/K 헤드(풋보드) + 파운데이션헤드/후드각1EA 수납파데 (위치조정) 서랍파데 Q확장파데 서랍및덮개 (패널없는경우) 마감스티커 2 / 2
    💡 조립이 빡빡하면

    헤드/풋보드 연결볼트가 완전히 조여진 상태에서는 확장 파데 조립이 어렵습니다. 연결볼트를 약간 풀어준 후 조립하면 수월합니다.

  15. 8

    패널 + 조명 설치

    패널에 T선반을 설치 → 뒷판(우라) 분리 → 조명 설치 → 헤드와 패널을 연결칩으로 결합 → 뒷판 재조립.

    조립도_패널T선반 조명 헤드연결 뒷판(우라) 마감스티커 1 / 3
  16. 8

    패널 + 조명 설치 이어서

    조립도_패널T선반 조명 헤드연결 뒷판(우라) 마감스티커 2 / 3
  17. 8

    패널 + 조명 설치 이어서

    조립도_패널T선반 조명 헤드연결 뒷판(우라) 마감스티커 3 / 3
    T선반 1ea연결칩 2ea스크류볼트 3ea조명 1ea
    ⚡ 조명 결선 주의

    LED 조명과 다른 어댑터를 함께 연결하면 정상 작동하지 않을 수 있습니다. 반드시 동봉된 터치스위치 + USB 포트만 사용하세요. (어댑터 ← 듀얼케이블 ← 터치스위치 + USB 포트 ← LED 바)
